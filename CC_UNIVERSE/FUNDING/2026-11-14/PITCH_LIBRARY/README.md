# Carnival Careers — Funding Pitch Library

**Created:** 14 November 2026

This directory includes all fifteen PDF pitch presentations, the PDF index and a SHA-256 integrity manifest.

- **Sponsorship:** global, Canada, and real-estate-only; with and without real estate where relevant.
- **Equity investors:** global, Canada, and real-estate-only; with and without real estate where relevant.
- **Startup lenders:** global, Canada, and real-estate-only; with and without real estate where relevant.

The individual PDFs are downloadable directly from this directory. `manifest.json` contains the source-file SHA-256 checksums for verification.

**Public repository disclosure:** These are working funding presentations. Stated financing, investor returns, acquisitions, sponsorship placements and other projections are proposals, not guaranteed or approved commitments.

The complete ZIP is stored here in eight exact binary parts. See [ARCHIVE_REASSEMBLY.md](ARCHIVE_REASSEMBLY.md) or run [reassemble-archive.ps1](reassemble-archive.ps1) to reconstruct and verify it.
