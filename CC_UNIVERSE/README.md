## File organization rules

**One original file, one canonical path, one primary department.** We organize using department indexes rather than duplicating or relocating working code, images, music and site files. This preserves website references and provenance. An individual archived file is only marked GitHub-stored when its actual bytes or ciphertext are in the repository. An Adobe or Drive registry entry does not mean the source is already imported.

**Financial lanes are separate:** Global pilot C$10,231,872 / 38 modeled homes; conditional Sammon case C$9,022,984 / 40 modeled homes (tenanted, NOI unknown); Toronto CC-CAPITAL65 development separate; full 65-city entertainment budget separate. Keep six tenant-owner households and a legal 4BR path; C$800 housing target is financing-dependent.

**Public repository:** never publish raw tenant records, bank data, unredacted contracts, mortgage documents, personal identity or private contact lists. Use strongly encrypted files, with key outside GitHub, or a separate private GitHub repo. No automatic third-party contact.
