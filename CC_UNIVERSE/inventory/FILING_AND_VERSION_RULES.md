# CC Universe — Filing & Version Rules

1. **GitHub is the permanent CC master.** No ChatGPT Library storage or substitute masters.
2. Search the [complete source inventory](GITHUB_FILE_MANIFEST.json) before making a new file. Prefer editing the correct original and record a commit, not creating generic replacements.
3. Every GitHub file gets exactly one primary workstream and can have multiple cross-links. Runtime website pages and scripts remain in their original root paths to preserve the build.
4. Record actual source path, Git blob SHA, size, current/versioned/historical state, dependencies, financing status and data provenance.
5. **Public privacy control:** encrypted archives only for confidential household, investor, contacts, KYC, financing or signed source documents. Keep keys and passwords out of GitHub, including issues and commit messages.
6. Every new/recovered asset must be added to its department README and machine-readable inventory; update the [external-source backlog](EXTERNAL_MASTERS_NOT_IN_GITHUB.md) when bytes are really committed.
7. Run `node tools/check-cc-universe-catalog.mjs` in a checked-out repo; any unindexed non-catalog path is a failed coverage check.
8. Preserve identical originals and signatures. Revised disclosures get a new date/version, never a changed historical original.
9. Do not count modeled NOI or projected rentals from owner-occupied family homes, and do not conflate global property, Toronto development, and arena/TV funding.
10. No automatic third-party outreach, application, signature or payment.

## Source status labels

- **GITHUB_PRESENT:** actual tracked bytes at the linked path.
- **ENCRYPTED_GITHUB_PRESENT:** encrypted bytes and recovery guide exist, not plaintext.
- **REGISTERED_EXTERNAL:** a known Adobe or other original is named in GitHub but source bytes are not.
- **HISTORICAL:** evidence preserved unchanged; not an active offer, lender approval or future event booking.
- **MODELED:** scenario assumptions, not independently verified contractual economics.
