## Disclosure levels
**L0 — First approach:** proposal summary, permitted publicly cleared music/press samples, broad credibility description, explicitly proposed rights and milestone payment outline. No financial account numbers, signatures, personal contact lists, unredacted sponsor memos or legal originals.

**L1 — Qualified authorized recipient:** detailed show-specific one-sheet, tech requirements, current proposed three-release addendum, limited/redacted evidence of historical execution, non-confidential quotes/letters expressly cleared for onward distribution. Verify source and disclosure permission first.

**L2 — Named authorized diligence team only:** complete original contracts, signed memos, invoices, rights chain-of-title, expense backup, budgets, supplier and brand proposals with explicit source status; NDA/access control and purpose-limited viewing. **Do not place plaintext originals in this PUBLIC GitHub repo.** An encrypted archive with the key outside GitHub or an access-controlled private GitHub repository is required; GitHub links cannot substitute for access control.
